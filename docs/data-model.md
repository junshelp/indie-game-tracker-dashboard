# 데이터 기준

- 행사 기간은 시간 없는 ISO 날짜입니다. 월별 목록은 시작 연·월 기준입니다.
- 현재 기준일은 한국 시간(Asia/Seoul)입니다. 종료일 당일까지 `upcoming`, 이후 `past`입니다. 따라서 진행중 행사도 예정/진행 목록에 포함됩니다.
- `upcoming30Days`는 예정 행사 중 시작일이 오늘부터 30일 뒤까지인 수입니다. 양 끝 날짜를 포함합니다.
- 생성 시각 `generatedAt`은 실제 UTC 시각이며 공식 출처의 최종 확인 시각을 의미하지 않습니다. `asOfDate`는 집계 기준 한국 날짜입니다.
- `snapshotId`는 행사 data/history/summary를 같은 묶음으로 식별합니다.
- `month`, 연-월 집계, 상태와 통계는 검증된 기간에서 파생합니다.
- URL이 미확인 또는 메모이면 `null`입니다. HTTP(S) 이외의 링크는 발행하지 않습니다.
- `submissionPeriod`는 원문 메모입니다. `submissionStatus`는 `open`, `closed`, `upcoming`, `unknown`입니다. 날짜 범위만 있고 현재 접수 상태가 명시되지 않으면 `unknown`을 유지합니다.
- 기존 행사 ID는 유지합니다. 새 행사는 국가·행사명에서 ID를 생성합니다. 이름을 바꾸는 경우 기존 ID/별칭 관계를 검토해야 하며 같은 날짜라는 이유로 합치지 않습니다.
- 변경 이력은 시작일과 종료일을 비교합니다. 첫 baseline 생성은 일괄 신규 발견으로 기록하지 않습니다.
- 날짜가 월 단위로만 알려진 행사는 정확한 타임라인에 넣지 않습니다. 원본 캘린더에는 유지합니다.

## Steam

`appid`가 식별자입니다. `wishlist_rank`는 popularwishlist 검색 결과의 상대 순위입니다. 수집 경로가 다른 `steam_rank`를 전체 시장 순위로 해석하지 않습니다.

상세 정보는 요청 예산 내에서 누락·오래된 appid부터 갱신하며 이전 정보를 재사용합니다. `metadataStatus`와 `metadataCheckedAt`으로 캐시/누락/실패를 구분합니다. 장르와 무료 게임 수는 확보된 메타데이터 범위에 한정됩니다.

날짜 원문을 보존하며 미정 날짜를 과거 날짜로 대체하지 않습니다. UI는 분기·연도 표기를 그 기간의 시작 시점으로 정렬하고 날짜 미정은 뒤에 배치합니다. 신규 배지는 최근 3일 이내 진입에만 표시합니다.
